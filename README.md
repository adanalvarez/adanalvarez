### Hi, I'm Adan 👋

Security architect & researcher at [A2SECURE](https://www.a2secure.com), based in Barcelona. I help security keep up with AI, and with attackers who use it.

Here I share the tools and research behind my articles: how attackers operate in AWS (more and more with AI), and practical ways to detect, deceive and contain them. Most of it comes with data and code, so you can run it yourself.

#### 🔬 AI-powered attacks
- **[llm-trails](https://github.com/adanalvarez/llm-trails)**: what LLMs reach for inside a breached AWS account, mapped to CloudTrail. [Explore the data](https://llms.traildiscover.cloud/).
- **[cloud-ranges](https://github.com/adanalvarez/cloud-ranges)**: synthetic cloud environments for testing how AI agents behave on real attack chains.

#### 🛡️ Detection and deception in AWS
- **[TrailDiscover](https://github.com/adanalvarez/TrailDiscover)**: CloudTrail events mapped to real-world incidents, research and MITRE ATT&CK. [traildiscover.cloud](https://traildiscover.cloud/)
- **[TrailAlerts](https://github.com/adanalvarez/TrailAlerts)**: AWS-native, serverless detection. Write simple rules as code and get rich alerts.
- **[HoneyTrail](https://github.com/adanalvarez/HoneyTrail)**: deploy honeyservices in AWS that alert on unauthorized access.

#### 🤖 AI for defense
- **[semgrep-llm-advisor](https://github.com/adanalvarez/semgrep-llm-advisor)**: Semgrep findings plus LLM recommendations for faster remediation.
- **[bedrock-secure-questionnaire-automation](https://github.com/adanalvarez/bedrock-secure-questionnaire-automation)**: answer security questionnaires from your own knowledge base, serverless on Amazon Bedrock.
